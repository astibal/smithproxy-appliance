INPUT{{ 'ENFORCED' if firewall.input_enforced else 'ALLOW / AUDIT' }}Přístup na samotný SAS host.
Co přesně se děje?
  1. Paket míří na službu samotného SAS hostu.
  2. Loopback a odpovědi existujících spojení projdou vždy.
  3. U nového IPv4 spojení se zkontroluje zdrojová IP proti INPUT seznamu.
  4. Při ENFORCED se neznámý zdroj zahodí. Při ALLOW / AUDIT zatím projde.
FORWARD → instance{{ 'ENFORCED' if firewall.forward_enforced else 'ALLOW / AUDIT' }}Pouze provoz mířící na ingress peer czi*.
Co přesně se děje?
  1. Host už rozhodl, že paket má jít do konkrétní instance.
  2. Filtr zasahuje jen při výstupu přes ingress peer czi*.
  3. Zdroj musí být ve spawn poolu nebo mít aktivní FORWARD autorizaci.
  4. Odpovědi existujících spojení a egress přes czo* se neblokují.
IPv6FIRST-CLASSSamostatné IPv6 sety, /126 lease a routing.
Co přesně se děje?
  1. INPUT a FORWARD mají oddělené interval sety pro IPv4 a IPv6.
  2. Každá nová instance dostane ke svému /30 také /126 se stejným lease indexem.
  3. Mark, policy route a transparentní proxy fungují pro obě rodiny.
  4. Staré instance bez IPv6 lease zůstávají IPv4-only až do nového spuštění.
